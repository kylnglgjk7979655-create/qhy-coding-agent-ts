# 完整会话记录保留原文，并作为恢复配置的依据

会话记录（Transcript）包含用户与助手消息、工具往返、轮次完成或中断状态，以及运行配置和配置变更。恢复会话时，以记录中最后生效的配置为准，凭据仍从当前环境读取；不采用当前启动配置默默覆盖既有会话配置的方式。

会话记录保留完整原文，摘要仅用于构造模型输入，不删除记录中的早期消息。这替代 ADR 0004 中只保存摘要后的有效历史、不归档原文及不保留失败轮次记录的约定，使中断过程与原始历史可被保留。摘要作为历史资料、不能改变系统提示或工具策略的约束继续适用。

恢复时按中断原因处理工具调用：用户主动中断时，未完成调用的结果记录为精确字符串 `Interrupt by user`；断电后无任何结果的调用不加入模型上下文，但仍保留在原始会话记录中；有部分结果的调用则纳入上下文。已完成调用的结果继续保留。部分结果的具体表示仍待细化。

摘要内容和覆盖的历史范围写入 transcript，恢复时直接复用，再接上后续消息；完整原文继续保留。transcript 写入失败时停止本轮，不再启动后续模型请求或工具调用，已经发生的文件副作用保留。这与文件检查点备份失败仅记录错误、继续编辑的规则不同。

会话数据统一存放于用户级根目录，例如 `~/.qhy-coding-agents/`，不依赖 CLI 的启动目录，也不放在工作区的 `.agent/` 中。具体目录结构与记录写入方式仍待确定。本次范围不包含 fork，也不提供旧格式对话的导入或迁移。

会话记录、检查点及文件备份持续保留，不设置自动过期或自动清理。

处理中用户主动中断只结束当前轮次，记录中断后返回 CLI 输入；空闲时 Ctrl+C 才退出。同一会话不允许两个进程同时使用，异常退出后仍应允许再次恢复。

会话绑定记录中的原工作区路径，不支持目录移动或改名后为原会话重新绑定新路径。原工作区路径失效时，恢复报错；用户级存储不意味着会话可以迁移到任意工作区。会话选择默认只列出当前工作区的会话，并提供查看全部会话的选项。
