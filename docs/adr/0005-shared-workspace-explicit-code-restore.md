# 多会话共用工作目录，代码恢复由用户显式选择

一个工作区允许多个会话，各自保留可恢复状态，但共用工作目录，不为会话创建隔离目录。由于恢复文件会改变所有会话看到的目录内容，继续或切换会话时不自动还原文件；用户主动选择恢复代码时，交互界面先显示将受影响的文件和改动统计，再由用户选择是否执行恢复。

预览依据文件差异，不专门识别修改来自用户、其他会话或其他进程，也不单独提示“手动修改将被覆盖”。该决策接受共用目录带来的相互影响，以显式代码恢复区分会话上下文的继续与文件内容的还原。

首版仅由内置 `write_file` 触发文件追踪；Bash 与 MCP 不作为追踪入口，也不承诺其任意副作用可恢复。已追踪文件的后续变化在下一条消息的检查点中记录，不按修改来源区分，具体规则见 ADR 0006。代码恢复保留已有对话，不随文件回退而截断消息历史。恢复操作的记录方式仍需后续确定。
