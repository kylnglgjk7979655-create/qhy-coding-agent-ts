# 宿主 Bash 通过统一审批执行，工作目录约束不提供隔离

> 用户主动中断场景的会话记录规则由 [ADR 0007](0007-session-transcript-source-of-truth.md) 细化：未完成工具调用的结果记为 `Interrupt by user`。本 ADR 中“不补造工具结果”的原有表述不再排除此明确的用户中断标记；进程终止与已有副作用不回滚的约束继续适用。

父需求 #6 的子任务 #11 将 `Bash` 注册为普通工具，复用现有 SDK 的串行循环、参数 schema 校验、调用 ID 关联以及公共工具策略、审批、结果和执行事件。默认进入所选审批，固定允许和拒绝继续优先；每次批准只对应本次命令及参数。

审批前解析 `cwd` 的实际路径并检查目录可用且位于工作区内；省略时使用工作区。人工审批同时展示原始完整参数和实际启动目录，模型审批仍只接收专用提示和本次工具名称、原始参数。拒绝或等待期间不启动进程。启动前重新核验已展示的实际目录，避免等待期间替换符号链接后使用改变的启动位置；变化或不可用时反馈单次失败，要求重新提交调用。

每次调用从 CLI 环境启动独立 Bash，不保留 shell 状态，不接受模型自定义环境参数。命令在 Linux/macOS 等支持 POSIX 进程组的宿主上，以当前用户权限执行。cwd 仅约束启动位置，不限制命令访问工作区外资源或网络；这不改变 ADR 0001 的内置文件工具边界，也不增加操作系统沙箱。

单次命令默认 30 秒上限，可通过 `bash.timeoutMs` 配置；同时受整轮剩余执行时限和父级取消信号约束。人工审批等待仍单独计时。命令使用独立进程组，超时或取消对所管理的进程组发送 SIGKILL；轮次退出前等待正在执行的命令结束，不以停止读取输出代替终止进程。不提供后台任务管理。

stdout 和 stderr 合计保存最多 64 KiB，超限仍消费流，结果明确标记截断。结果同时提供退出码、终止信号和可用文本；非零退出、启动失败及单命令超时作为调用失败，同批后续普通调用继续。整轮超时与取消继续走轮次停止通路，不补造工具结果，也不回滚已发生的宿主副作用。

自动验证从编译后 CLI、本地模型协议请求、实际文件和受控进程状态观察行为，不增加产品内部测试入口；最终人工 QA 仍需由人完成。
